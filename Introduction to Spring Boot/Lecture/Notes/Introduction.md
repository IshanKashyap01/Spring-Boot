# Introduction to Spring Boot

We will learn about the following:

1. Fundamentals of Spring

2. Spring MVC

3. REST API

4. Databases

5. Spring DATA

6. Spring Security

7. Microservices

## Pre-requisites

1. Basics of Java

2. Object Oriented Programming

3. Basics of HTML and CSS

## Advantages of Spring Boot

1. It is very secure and it is built on top of Java, which itself is quite
secure

2. It is scalable to global levels

3. It has high performance

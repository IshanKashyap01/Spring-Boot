# Spring Security Features

## Authentication

The process of verifying the identity of a user

## Authorization

The process of determining what permissions they have

## Two-Factor Authentication

Verification method that requires two different types of evidence before
allowing access

## OAuth

Open-standard authorization framework that *delegates authorization* to a third
party app

## OpenID Connect (OIDC)

Sits on top of OAuth and *delegates authentication* to a third party app

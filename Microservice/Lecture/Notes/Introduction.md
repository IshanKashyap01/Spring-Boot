# Introduction to Microservices

## Key Principles

1. **SRP** each microservice does one thing only

2. **Loose coupling / high cohesion**

3. **Fault isolation**

4. **Scalability**

5. **Polygot Persistence** each microservice can have its own dedicated SQL or
NoSQL database

6. **Decentralised/Autonomy**

7. **Continuous Development** they can be developed and deployed in parallel

## Microservice vs Monolith

Compared to monoliths, microservices have the following advantages:

1. **Complexity**: are less complex

2. **Development**: takes less time to complete

3. **Scalability**: scales up easier

4. **Fault Isolation**: easier to find and isolate faults

- However, due to more network calls involved, monoliths have faster
communication

# Derived Queries

- They are DB queries automatically generated by Spring Data JPA based on the
naming convention of the method

```java
public interface UserRepository extends JpaRepository<User, Integer>
{
    int findByAgeGreaterThan(int age);
}
```

- First, you need to add a method with the correct naming convention to the
interface

```java
public List<User> findUsersWithAgeGreaterThan(int age)
{
    return userRepository.findByAgeGreaterThan(age);
}
```

- Then you can call those methods without breaking backwards compatibility as
Spring creates the implementation dynamically at runtime
